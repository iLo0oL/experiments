🔑 مفتاح YouTube API (اختياري)

التطبيق يشتغل بدونه، بس المفتاح يخلي البحث والرئيسية أسرع وأثبت.

كيف أجيب المفتاح؟
  1. افتح Google Cloud Console وسجّل بحساب قوقل.
  2. أنشئ مشروع جديد، ثم اضغط Enable على YouTube Data API v3.
  3. من Credentials اختر Create credentials ← API key وانسخه.

📲 تثبيت تيوبي

  1. آيفون (Safari): اضغط زر المشاركة ⬆️ تحت، ثم «إضافة إلى الشاشة الرئيسية».
  2. أندرويد (Chrome): اضغط ⋮ فوق، ثم «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
