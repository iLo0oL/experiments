# سيرفر أنميتي

سيرفر صغير يشغّل المزايا اللي تحتاج قاعدة بيانات:

- **حسابات:** اسم مستخدم وكلمة سر، ورمز استرجاع إذا نسيت كلمة السر.
- **مزامنة:** قائمتك وتقييماتك وترتيبك تتزامن بين كل أجهزتك.
- **تنبيهات بالجوال:** لما تنزل حلقة من اللي تتابعه، حتى لو الموقع مسكّر.
- **الشلة المباشرة:** تضيف ربعك برمز الصداقة وتشوفون قوائم بعض لحظة بلحظة.
- **السهرات:** تعزم الشلة على حلقة بموعد، ويجيكم تذكير قبلها بربع ساعة.

## التشغيل على Railway

1. افتح [railway.com](https://railway.com) وسجّل دخول.
2. اضغط **New Project** ← **Deploy from GitHub repo** ← اختار `iLo0oL/experiments`.
   إذا طلب صلاحية الوصول للمستودع، وافق.
3. افتح الخدمة اللي انسوت ← **Settings** ← **Root Directory** واكتب:
   ```
   anime-server
   ```
4. ارجع للمشروع واضغط **New** (أو **Create**) ← **Database** ← **PostgreSQL**.
5. افتح خدمة السيرفر ← **Variables** ← **New Variable**:
   - الاسم: `DATABASE_URL`
   - القيمة: اختار المرجع من قاعدة البيانات `${{Postgres.DATABASE_URL}}`
6. خدمة السيرفر ← **Settings** ← **Networking** ← **Generate Domain**.
   يطلع لك رابط مثل `https://xxxx.up.railway.app`.
7. افتح الرابط وزيد عليه `/health`، لازم يطلع لك `{"ok":true}`.
8. افتح أنميتي ← **إحصائياتي** ← **الإعدادات** ← **رابط السيرفر**، والصق الرابط واضغط حفظ.

## المتغيرات

| المتغير | لازم؟ | وش يسوي |
|---|---|---|
| `DATABASE_URL` | ✅ | رابط قاعدة بيانات Postgres |
| `ALLOW_ORIGINS` | لا | المواقع المسموح لها تكلّم السيرفر. الافتراضي `https://ilo0ol.github.io` |
| `APP_URL` | لا | رابط الموقع اللي تفتحه التنبيهات. الافتراضي `https://ilo0ol.github.io/experiments/anime/` |
| `PGSSL` | لا | حطه `1` إذا قاعدة البيانات تطلب اتصال آمن (SSL) |
| `ADMIN_KEY` | لا | مفتاح المدير (12 حرف أو أكثر). يفعّل صفحة `#/admin` اللي ترجّع فيها حساب واحد نسي كلمة السر ورمز الاسترجاع |

مفاتيح التنبيهات (VAPID) تنولد تلقائي أول ما يشتغل السيرفر، وتنحفظ بقاعدة البيانات، فما تحتاج تسوي شي.

## إذا أحد نسي كلمة السر ورمز الاسترجاع

1. تأكد إنه فعلاً صاحب الحساب.
2. افتح `https://ilo0ol.github.io/experiments/anime/#/admin` واكتب `ADMIN_KEY`.
3. دوّر على اسم المستخدم حقه ← **طلّع له رمز استرجاع جديد** ← أرسله له.
4. هو يفتح أنميتي ← سجّل دخول ← **نسيت كلمة السر**، ويكتب الرمز وكلمة سر جديدة.

المفتاح ينحفظ بس لين تسكّر التطبيق، وما ينحفظ بالجهاز.

## ملاحظات

- التنبيهات بالآيفون تشتغل بس إذا أنميتي مثبّت على الشاشة الرئيسية (iOS 16.4 أو أحدث).
- السيرفر يشيّك على الحلقات الجديدة كل 10 دقايق، وعلى السهرات كل دقيقة.
- كلمات السر تنحفظ مشفّرة (scrypt)، وملاحظاتك الخاصة ما تطلع لربعك أبداً.
