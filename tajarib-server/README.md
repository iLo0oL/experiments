# سيرفر تجارب المشترك

سيرفر واحد يخدم كل التطبيقات اللي تحتاج مشاركة مباشرة:

| التطبيق | وش يستفيد من السيرفر |
|---|---|
| 💸 القطّة | الشلة كلها تضيف مصاريفها بنفس الطلعة، والحسابات تتحدّث عند الكل |
| 🌳 شجرتنا | العائلة تضيف على نفس الشجرة، ورابط عرض بس لباقي الأقارب |
| 🛒 مقاضي | البيت كله يشوف نفس القائمة، ولما أحد يشتري شي يتشطب عند الكل |
| 🍽️ منيو | تعدّل المنيو من جوالك، ويتحدّث عند الزباين على طول |
| 📅 موعد | الزباين يحجزون، والسيرفر يمنع تعارض المواعيد ويرسل لك تنبيه |

كل التطبيقات تشتغل بدون السيرفر على جهاز واحد. السيرفر بس يضيف المشاركة.

## كيف تنحفظ البيانات؟

- كل قائمة أو شجرة أو منيو أو جدول مواعيد هو «مستند» له مفتاحين:
  - **مفتاح التعديل:** لك وللي تشاركهم.
  - **مفتاح العرض:** قراءة بس، مثل منيو الزباين أو صفحة الحجز.
- المفاتيح تنحفظ بالسيرفر مشفّرة، فحتى صاحب السيرفر ما يقدر يعرفها.
- لو انسرق رابط، تقدر تغيّره من التطبيق، والرابط القديم يوقف.
- أسماء وأرقام اللي يحجزون في «موعد» يشوفها صاحب الجدول بس.

## التشغيل على Railway

1. افتح [railway.com](https://railway.com) ← **New Project**.
2. **Database** ← **PostgreSQL**.
3. **Create** ← **GitHub Repository** ← `iLo0oL/experiments`.
4. افتح مربع السيرفر ← **Settings** ← **Root Directory**، واكتب:
   ```
   tajarib-server
   ```
5. **Variables** ← اضغط **Add Variable** اللي يطلع جنب «Trying to connect a database?»، أو أضف المتغيّر بنفسك:
   - الاسم: `DATABASE_URL`
   - القيمة: `${{Postgres.DATABASE_URL}}`
6. **Settings** ← **Networking** ← **Generate Domain**. إذا سألك عن المنفذ، اكتب `8080`.
7. اضغط **Deploy**.
8. افتح الرابط وزيد بآخره `/health`، لازم يطلع لك `{"ok":true}`.

لا تشغّل **Under Attack Mode** ولا **CDN Caching**، لأنهم يخرّبون المزامنة.

## المتغيرات

| المتغير | لازم؟ | وش يسوي |
|---|---|---|
| `DATABASE_URL` | ✅ | رابط قاعدة بيانات Postgres |
| `ALLOW_ORIGINS` | لا | المواقع المسموح لها تكلّم السيرفر. الافتراضي `https://ilo0ol.github.io` |
| `SITE_URL` | لا | رابط التجارب اللي تفتحه التنبيهات. الافتراضي `https://ilo0ol.github.io/experiments/` |
| `PGSSL` | لا | حطه `1` إذا قاعدة البيانات تطلب اتصال آمن (SSL) |

مفاتيح التنبيهات تنولد تلقائي أول ما يشتغل السيرفر.

## ملاحظات

- المستند اللي ما انفتح سنة وشوي (400 يوم) ينحذف تلقائي، عشان قاعدة البيانات ما تكبر بدون فايدة.
- أقصى حجم للمستند 3 ميغا، وهذا يكفي آلاف العناصر.
- فيه حد للمحاولات على الإنشاء والحجز عشان ما أحد يعبث بالسيرفر.
