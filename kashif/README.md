# 🔍 كاشف (اسم مؤقت)

تطبيق ويب يشتغل على الجوال: تكتب رقم جوال (سعودي افتراضياً +966) وتضغط بحث، ويعرض لك المعلومات المتاحة عن الرقم **بطرق نظامية فقط**.

- **تحليل الرقم:** الصيغة الدولية والمحلية، والدولة، وهل الرقم صالح، ونوعه (جوال، ثابت، مجاني، موحّد…). نستخدم لها libphonenumber.
- **الاسم:** يظهر فقط إذا صاحب الرقم سجّل بنفسه، وتحقق من رقمه برمز، ووافق صراحةً إن اسمه يظهر.
- **البلاغات:** عدد اللي بلّغوا عن الرقم إنه مزعج أو احتيال، بدون أسماء المبلّغين.
- **شركة الاتصالات ونوع الخط (اختياري):** عبر Twilio Lookup.
- **ابحث في تطبيقات أخرى:** أزرار تفتح واتساب وتيليجرام وتروكولر وقوقل والرقم مكتوب فيها، والبحث يسويه المستخدم بنفسه.

ما نرفع جهات الاتصال، ولا نسحب بيانات من أي خدمة ثانية، ولا نحفظ الأرقام اللي ينبحث عنها.

## الخطة: التقنيات وهيكل المشروع

| الجزء | التقنية | ليش |
|---|---|---|
| السيرفر | Node.js 22 + Express 5 | بسيط ومعروف، ونفس لغة الواجهة |
| قاعدة البيانات | SQLite (`node:sqlite` المدمجة في Node) | ما تحتاج تثبيت شي ولا برامج مبنية، وتكفي للنسخة الأولى. ننقلها لـ Postgres لاحقاً لو احتجنا |
| الأرقام | `libphonenumber-js` (بيانات max) | التنسيق والتحقق ونوع الرقم |
| الواجهة | HTML و CSS و JS بدون إطار | خفيفة على الجوال، عربية من اليمين لليسار، وتقدر تثبّتها كتطبيق (PWA) |
| الحماية | `helmet` (CSP وباقي الهيدرز) + حدود للطلبات محفوظة في قاعدة البيانات | ضد الجمع الآلي والعبث |
| رسائل التحقق | وضع تطوير (الرمز يطلع في الطرفية)، أو Twilio Verify | |
| الاختبارات | `node:test` المدمج | ما يحتاج مكتبات |

```

│   ├── config.js        قراءة الإعدادات من .env
```

### جداول قاعدة البيانات

| الجدول | وش فيه |
|---|---|
| `users` | الرقم (E.164)، الاسم، وقت الموافقة على ظهوره، مخفي أو لا، وقت قبول الشروط |
| `otps` | رمز تحقق واحد معلّق لكل رقم، محفوظ مشفّر (HMAC)، وينتهي بعد 5 دقايق |
| `sessions` | الجلسات، محفوظة مشفّرة (SHA-256) |
| `reports` | بلاغ واحد لكل مستخدم على كل رقم (مزعج أو احتيال)، وينحذف بعد سنة |
| `lookup_cache` | نتائج Twilio Lookup لمدة 30 يوم عشان نقلل التكلفة |
| `rate_limits` | عدّادات الحدود. فيها رقم المستخدم أو بصمة مشفّرة من الـ IP، وتنحذف بعد يومين |

## التشغيل المحلي

يحتاج **Node.js 22.13 أو أحدث**.

```bash
cd kashif
npm install
cp .env.example .env     # اختياري، بدونه يشتغل بالإعدادات الافتراضية
npm start                # أو npm run dev عشان يعيد التشغيل مع كل تعديل
```

افتح http://localhost:3000

**تسجيل الدخول محلياً:** في وضع التطوير (`OTP_PROVIDER=console`) ما تنرسل رسالة. رمز التحقق يطلع في طرفية السيرفر، ويطلع كمان في صفحة الدخول تحت مربع الرمز.

**تجربة البلاغات:** العدد ما يظهر إلا لما يوصل 3 بلاغات من 3 حسابات مختلفة. عشان تجربها بسرعة، حط `REPORTS_MIN_TO_SHOW=1` في `.env`.

**تجربة الجوال على نفس الشبكة:** افتح `http://<IP-جهازك>:3000` من الجوال.

**الاختبارات:**

```bash
npm test
```

## الإعدادات (`.env`)

| المتغير | الافتراضي | وش يسوي |
|---|---|---|
| `PORT` | `3000` | المنفذ |
| `APP_SECRET` | (لازم في التشغيل الفعلي) | مفتاح سري لتشفير رموز التحقق وبصمات الـ IP |
| `DEFAULT_COUNTRY` | `SA` | الدولة لما ينكتب الرقم بدون رمز دولة |
| `DB_PATH` | `./data/kashif.db` | مكان قاعدة البيانات |
| `TRUST_PROXY` | `0` | حطه `1` إذا السيرفر خلف بروكسي (Railway أو Nginx أو Cloudflare) |
| `OTP_PROVIDER` | `console` | `console` للتجربة، و`twilio_verify` لرسائل SMS حقيقية |
| `TWILIO_ACCOUNT_SID` / `TWILIO_AUTH_TOKEN` | | مفاتيح Twilio |
| `TWILIO_VERIFY_SERVICE_SID` | | مطلوب مع `twilio_verify` |
| `TWILIO_LOOKUP_ENABLED` | `false` | `true` يعرض شركة الاتصالات ونوع الخط |
| `SEARCHES_PER_MINUTE` | `5` | حد البحث بالدقيقة |
| `SEARCHES_PER_DAY` | `30` | حد البحث باليوم لكل مستخدم مسجّل |
| `ANON_SEARCHES_PER_DAY` | `10` | حد البحث باليوم بدون حساب (لكل IP) |
| `REPORTS_PER_DAY` | `20` | حد البلاغات باليوم لكل مستخدم |
| `OTP_PER_PHONE_PER_15_MIN` | `3` | حد طلب رموز التحقق لكل رقم |
| `OTP_PER_IP_PER_HOUR` | `10` | حد طلب رموز التحقق لكل IP |
| `API_REQUESTS_PER_MINUTE` | `60` | حد عام لكل IP |
| `REPORTS_MIN_TO_SHOW` | `3` | أقل عدد بلاغات عشان يظهر العدد |
| `REPORTS_RETENTION_DAYS` | `365` | البلاغات الأقدم من كذا تنحذف |

### تفعيل Twilio

1. سوّ حساب في [twilio.com](https://www.twilio.com) وخذ `Account SID` و`Auth Token` من الصفحة الرئيسية للحساب.
2. **رسائل التحقق:** من **Verify → Services** سوّ خدمة جديدة وخذ `Service SID` (يبدأ بـ `VA`). بعدها حط في `.env`:
   ```
   OTP_PROVIDER=twilio_verify
   TWILIO_VERIFY_SERVICE_SID=VA...
   ```
3. **شركة الاتصالات:** حط `TWILIO_LOOKUP_ENABLED=true`. كل بحث جديد يكلّف حسب تسعيرة Line Type Intelligence، والنتيجة تنحفظ 30 يوم.

> ملف `.env` موجود في `.gitignore`، فالمفاتيح ما تنرفع على GitHub.

## الحماية والخصوصية: وش سوينا

- **ضد الجمع الآلي:**
  - الاسم وأعداد البلاغات ومعلومات شركة الاتصالات تظهر للمستخدمين المتحقّقين برقمهم بس.
  - فيه حد للبحث بالدقيقة وباليوم لكل مستخدم، وحد أقل بدون حساب.
  - فيه حد لطلب رموز التحقق لكل رقم ولكل IP.
- **البحث يرسل الرقم بطلب POST** عشان ما يطلع في الروابط ولا سجل المتصفح ولا سجلات السيرفر. وما نحفظ الأرقام اللي ينبحث عنها.
- **الـ IP ما ينحفظ.** نحفظ بصمة مشفّرة منه بالمفتاح السري، وتنحذف خلال يومين.
- **الموافقة على ظهور الاسم صريحة:** مربع منفصل لازم ينحدد كل مرة يتعدّل فيها الاسم، ووقت الموافقة ينحفظ.
- **الإخفاء:** يخفي الاسم بس. البلاغات تبقى تظهر كأعداد، عشان المحتال ما يسجّل ويخفي رقمه ويهرب من البلاغات.
- **البلاغات:**
  - بلاغ واحد لكل شخص على كل رقم، ويقدر يسحبه.
  - ما تقدر تبلّغ عن رقمك.
  - العدد ما يظهر إلا من 3 بلاغات، عشان بلاغ كيدي واحد ما يأثر.
- **حقوق نظام حماية البيانات الشخصية:** نسخة من بياناتك (JSON)، وتعديل الاسم، وحذف الاسم وسحب الموافقة، وحذف الحساب نهائياً مع بلاغاتك. كلها من صفحة «حسابي».
- **الهيدرز:**
  - CSP يمنع أي سكربت من خارج الموقع.
  - `Referrer-Policy: no-referrer`.
  - منع عرض الموقع داخل إطار في موقع ثاني.
  - أي طلب يعدّل بيانات من موقع ثاني ينرفض.
- **حذف تلقائي:** رموز التحقق والجلسات المنتهية، والعدّادات، والكاش، والبلاغات الأقدم من سنة.
