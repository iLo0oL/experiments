# إعداد الإضافات الاختيارية في «صراحة»

الصفحة تشتغل كاملة بدون أي إعداد. الإضافتين تحت **اختياريتين**: لو `config.js` فاضي ما يتغير أي شي، ولا تطلع خياراتهم في الصفحة أصلًا.

| الإضافة | وش تسوي | وش تحتاج |
|---|---|---|
| 💾 الجلسات الطويلة | الجلسات الجديدة تبقى محفوظة أكثر من 12 ساعة | مشروع Firebase مجاني (Realtime Database) |
| ✨ إعادة الصياغة بالذكاء الاصطناعي | تعيد كتابة الرسائل المجهولة بأسلوب محايد عشان ما يُعرف كاتبها | حساب Cloudflare مجاني + مفتاح Claude API |

بعد ما تجهّز أي وحدة منهم، حط رابطها في `config.js` وارفع التعديل:

```js
window.SARAHA_CONFIG = {
  firebaseUrl: 'https://my-saraha-default-rtdb.firebaseio.com',
  aiUrl: 'https://saraha-ai.my-name.workers.dev'
};
```

## 💾 الجلسات الطويلة (Firebase)

الرسائل تبقى **مشفرة بالكامل** مثل ntfy بالضبط: مفتاح الجلسة في الرابط بعد `#` وما يوصل لـ Firebase أبد. Firebase يحفظ نص مشفر بس.

1. ادخل [console.firebase.google.com](https://console.firebase.google.com) وسوّ مشروع جديد (Analytics ما تحتاجه).
2. من القائمة: **Build ← Realtime Database ← Create Database**، اختر أقرب موقع، وابدأ بـ **Locked mode**.
3. من تبويب **Rules** الصق القواعد هذي واضغط **Publish**:

```json
{
  "rules": {
    ".read": false,
    ".write": false,
    "t": {
      "$topic": {
        ".read": "$topic.matches(/^fb_[A-Za-z0-9_-]{20}$/)",
        ".write": "!newData.exists() && root.child('o').child($topic).exists() && newData.parent().parent().child('del').child($topic).val() == root.child('o').child($topic).val()",
        "$msg": {
          ".write": "$topic.matches(/^fb_[A-Za-z0-9_-]{20}$/) && !data.exists() && newData.exists()",
          ".validate": "newData.hasChildren(['m', 't']) && newData.child('m').isString() && newData.child('m').val().length <= 4096 && newData.child('t').val() == now",
          "$other": { ".validate": "$other == 'm' || $other == 't'" }
        }
      }
    },
    "o": {
      "$topic": {
        ".write": "$topic.matches(/^fb_[A-Za-z0-9_-]{20}$/) && !data.exists()",
        ".validate": "newData.isString() && newData.val().length == 32"
      }
    },
    "del": {
      "$topic": {
        ".write": "root.child('o').child($topic).exists()",
        ".validate": "newData.val() == root.child('o').child($topic).val()"
      }
    }
  }
}
```

   القواعد هذي تعني:
   - محد يقدر يشوف قائمة الجلسات. تقدر تقرأ جلسة بس إذا تعرف اسمها العشوائي (وهو في الرابط).
   - الرسالة تُضاف مرة وحدة، ومحد يقدر يعدّلها.
   - حجم الرسالة محدود، ووقتها من سيرفر Firebase نفسه.
   - المشرف بس يقدر يحذف جلسته كاملة: وقت الإنشاء يحفظ رمز سري في `o` (ما أحد يقدر يقرأه)، ووقت الحذف يرسل نفس الرمز في `del`، والحذف ما يمشي إلا لو الرمز مطابق.

   > لو عندك القواعد القديمة (قبل خيار الحذف)، بدّلها بهذي. الجلسات القديمة تكمل عادي، بس بدون زر الحذف.

4. انسخ رابط قاعدة البيانات اللي فوق في صفحة **Data** (شكله `https://اسم-المشروع-default-rtdb.firebaseio.com`) وحطه في `firebaseUrl`.

**ملاحظات:**
- الجلسات القديمة (اللي على ntfy) تكمل عادي. الجديدة بس تروح لـ Firebase، والمشرف يقدر يشيل علامة «💾 جلسة طويلة» وقت الإنشاء لو يبيها مؤقتة.
- بعد الكشف، المشرف يشوف زر «🗑️ احذف من السيرفر» يحذف كل رسائل الجلسة نهائيًا (والقوائم المحفوظة فيها نفس الزر لصاحبها). النتائج تبقى في الجوالات اللي شافتها.
- الصور في «ذكريات الشلة» و«صندوق الاقتراحات» تُصغَّر وتُشفَّر وتُحفظ على أجزاء مثل الرسائل، فمع Firebase تبقى دايم.
- الخطة المجانية (Spark) فيها حد للتخزين والتحميل يكفي لاستخدام الشلة بشكل عادي. لو تبي تنظف الجلسات القديمة، احذف العناصر تحت `t` من لوحة Firebase.

## ✨ إعادة الصياغة بالذكاء الاصطناعي (Claude)

مفتاح الـ API **ما يُوضع في الصفحة أبد**، لأن أي أحد يقدر يشوفه. بدال كذا فيه خادم صغير في مجلد `ai-worker` يحفظ المفتاح عنده، والصفحة تكلّمه هو.

### كيف تشتغل
1. المشرف يفعّل «✨ إعادة الصياغة بالذكاء الاصطناعي» وقت إنشاء الجلسة (يطلع الخيار بس للألعاب اللي فيها كتابة).
2. لما أحد يكتب رسالة مجهولة، النص يُرسل للخادم **قبل التشفير**، والخادم يرسله لـ Claude يعيد صياغته.
3. الكاتب يشوف النتيجة قبل الإرسال، ويقدر يرجع للتصحيح العادي بضغطة.
4. لو الخادم ما رد خلال 9 ثواني أو صار أي خطأ، الصفحة تكمل بالتصحيح العادي داخل الجوال.

> تنبيه للخصوصية: مع هذي الإضافة النص الأصلي يطلع من الجوال لخادمك ولـ Anthropic. لهذا هي مقفلة إلا إذا المشرف فعّلها لجلسته.

### خطوات التشغيل
1. سوّ حساب في [platform.claude.com](https://platform.claude.com) وطلّع مفتاح API.
2. سوّ حساب مجاني في [Cloudflare](https://dash.cloudflare.com)، وثبّت [Node.js](https://nodejs.org) على جهازك.
3. من مجلد `saraha/ai-worker`:

```bash
npm install
npx wrangler login
npx wrangler secret put ANTHROPIC_API_KEY   # الصق المفتاح لما يطلبه
npx wrangler deploy
```

4. بيطلع لك رابط مثل `https://saraha-ai.my-name.workers.dev`. حطه في `aiUrl` داخل `config.js`.
5. لو موقعك مو `https://ilo0ol.github.io`، عدّل `ALLOWED_ORIGIN` في `ai-worker/wrangler.toml` (تقدر تحط أكثر من موقع وتفصل بينها بفاصلة) وسوّ `npx wrangler deploy` مرة ثانية.

### تفاصيل الخادم
- النموذج: `claude-opus-5-5` بجهد منخفض (`effort: low`) عشان الرد يكون سريع.
- **مفعّل فيه الرجوع للنموذج الاحتياطي من جهة الخادم** (`server-side-fallback`): لو رفض النموذج رسالة عادية بالغلط، Anthropic تعيد المحاولة تلقائيًا على النموذج الاحتياطي المناسب. ولو رُفضت فعلًا، الخادم يرجّع خطأ والصفحة تكمل بالتصحيح العادي.
- يقبل الطلبات من المواقع اللي في `ALLOWED_ORIGIN` بس، والنص لين 800 حرف.
- ما يحفظ أي رسالة عنده.
